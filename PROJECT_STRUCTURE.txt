Core Components:
===============

🎯 ArsSkinManager
  • Singleton pattern for global skin management
  • Theme mode switching (LIGHT/DARK)
  • Skin package loading/unloading
  • Theme change listener management
  • Resource querying and retrieval

📦 SkinLoader
  • Load from Assets directory
  • Load from external storage
  • Manage installed skin packages
  • Delete and clear operations

🔄 ResourceOverlayHelper
  • OverlayManager API wrapper (Android 14+)
  • Enable/disable overlays
  • Query overlay information
  • System-level overlay management

🎨 SkinAttribute
  • Parse view skinning attributes
  • Apply resources to views
  • Support common attributes:
    - background
    - src
    - textColor
    - drawable*

📱 ArsApplication
  • Base Application class
  • Auto-initialization
  • Easy integration

🖼️ ArsActivity
  • Base Activity class
  • Auto-skinning support
  • Theme change handling
  • Simplified API

Usage Example:
=============

// 1. Extend ArsApplication
class MyApp : ArsApplication()

// 2. Extend ArsActivity
class MyActivity : ArsActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        
        // Load skin
        val skinLoader = SkinLoader(this)
        val path = skinLoader.loadFromAssets("skin.apk", "skin.apk")
        path?.let { loadSkin(it) }
        
        // Switch theme
        switchTheme(ArsSkinManager.ThemeMode.DARK)
        
        // Reset skin
        resetSkin()
    }
}
